# Noir 2048 — сайт SKRAY

Статический сайт: HTML, CSS и JavaScript. Сборка и сервер приложений не нужны.

## Просмотр

Откройте `index.html` в браузере. Для проверки через локальный HTTP-сервер:

```sh
python -m http.server 8000
```

Затем откройте http://localhost:8000/ .

## GitHub Pages

1. Распакуйте `Noir_2048_GitHub_Pages.zip` на компьютере. Сам ZIP загружать в репозиторий не нужно.
2. В GitHub создайте отдельный репозиторий для сайта Noir 2048, например `noir_2048_site`. Для бесплатного GitHub Free выберите Public. Репозиторий Brain Blitz оставьте отдельным.
3. Откройте репозиторий. Через Add file → Upload files (или ссылку uploading an existing file в пустом репозитории) загрузите все распакованные файлы и папку `assets` в корень, включая `.nojekyll`. Сохраните загрузку кнопкой Commit changes. `index.html` должен лежать непосредственно в корне, рядом с `en.html`, `terms.html` и `privacy.html`, без дополнительной общей папки.
4. Откройте Settings → Pages → Build and deployment. В Source выберите Deploy from a branch, затем ветку main и папку /(root). Нажмите Save. Если ветка названа иначе, выберите ветку с загруженными файлами.
5. Дождитесь успешной публикации. GitHub покажет адрес сайта в Settings → Pages. Если публикация завершилась с ошибкой, откройте вкладку Actions и посмотрите результат pages build and deployment.
6. Проверьте по опубликованному адресу демо, переключение RU/EN и стилей, обе страницы документов и их кнопки «Назад». При следующем обновлении замените изменённые файлы в той же ветке: GitHub Pages опубликует изменения автоматически.

Адрес проекта имеет вид `https://<имя-аккаунта>.github.io/<имя-репозитория>/`. Это шаблон, а не уже опубликованная ссылка. Страницы документов доступны по тому же адресу с `terms.html` или `privacy.html` в конце; английские версии — `terms.en.html` и `privacy.en.html`.

Сайт занимает около 2 МБ. GitHub Pages размещает статические HTML, CSS, JavaScript и ресурсы, в том числе несколько отдельных страниц. Демо работает в браузере, отдельный сервер для него не нужен. Сборка Node.js и собственный workflow GitHub Actions для этого архива не требуются.

Официальные инструкции: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

Все внутренние пути относительные, поэтому сайт работает и в подпапке репозитория.

## Страницы

- `index.html` — русский сайт, `en.html` — английский.
- `terms.html` / `terms.en.html` — страницы пользовательского соглашения.
- `privacy.html` / `privacy.en.html` — страницы политики конфиденциальности.
- `help.html` / `help.en.html` — полная справка Noir 2048 на русском и английском.

Страницы документов содержат полный текст из утверждённых `user_agreement.md` и `privacy_policy.md`. Русские формулировки перенесены без изменений; английские страницы содержат перевод. Дата 17.09.2026 и версия 0.2.21 сохранены из исходных документов. Страницы открываются напрямую и читаются без JavaScript; кнопки RU/EN открывают полный документ на выбранном языке.

## Текущее обновление: скругление плиток

Устранена повторная обрезка SVG-плиток контейнером с фиксированным скруглением. Пустые клетки, подсветка удаления и резервные плитки используют скругление, пропорциональное размеру плитки (10/78, как в оригинальных SVG). Цветная рамка сохраняется при уменьшении поля и масштаба.

Для этой правки замените `styles.css` в корне существующего репозитория и сохраните Commit changes в ветку, используемую GitHub Pages. Инструкцию `README.md` можно обновить вместе с ним. После успешной публикации в Actions обновите сайт с Ctrl+F5 и проверьте три оформления на телефоне и при уменьшении окна.

Архив содержит полный сайт, включая документы из предыдущего обновления. Если они ещё не загружены, используйте перечень ниже или загрузите всё содержимое архива с заменой.

## Предыдущее обновление: документы

Распакуйте архив. Загрузите в корень существующего репозитория с заменой:

- `terms.html`, `terms.en.html` — полное пользовательское соглашение.
- `privacy.html`, `privacy.en.html` — полная политика конфиденциальности.
- `legal.js` — переключение языка с сохранением номера раздела (новый файл).
- `styles.css` — оформление документов для компьютера и телефона.
- `README.md` — эта инструкция.

Остальные файлы в этом обновлении не менялись. Можно также загрузить всё содержимое архива с заменой. Не загружайте сам ZIP и не помещайте файлы в дополнительную общую папку.

1. Откройте существующий репозиторий → Add file → Upload files. Перетащите перечисленные файлы и нажмите Commit changes. Выберите ту же ветку, которая указана в Settings → Pages (обычно main).
2. При уже настроенном Pages изменения публикуются автоматически. Повторно включать Pages не нужно.
3. На вкладке Actions дождитесь успешного выполнения pages build and deployment. Затем откройте адрес сайта из Settings → Pages. Если показывается старая страница, обновите её с Ctrl+F5.
4. Откройте соглашение и политику через ссылки внизу сайта и напрямую по их URL. Проверьте начало и конец текста, RU/EN, кнопку «Назад» и чтение на телефоне. Справка и демо продолжают работать как раньше.

Пути для приложения: `terms.html` и `privacy.html`; английские версии — `terms.en.html` и `privacy.en.html`. Добавьте имя файла к опубликованному адресу сайта, заканчивающемуся `/`. Ссылки на эти страницы остаются прежними.

### Получение публичного адреса для кнопки «Подробнее»

Скопируйте точный опубликованный адрес сайта из Settings → Pages. К адресу его корня, заканчивающемуся `/`, добавьте `help.html` для русского языка или `help.en.html` для английского. Например, для шаблонного корня `https://<аккаунт>.github.io/<репозиторий>/` путь будет `https://<аккаунт>.github.io/<репозиторий>/help.html`. Это шаблон; замените его реальным адресом после публикации.

Откройте получившийся URL напрямую и убедитесь, что загружается справка, затем используйте его в игре. Пришлите реальный адрес сайта или ссылку на репозиторий, чтобы получить точные ссылки без предположений. Адрес версии для проверки в ChatGPT не является вашим адресом GitHub Pages.

Постоянные якоря одинаковы в обоих языках: `#boosts` — усилители, `#undo` — отмена хода, `#delete` — удаление плитки, `#currency` — монеты и кристаллы, `#coin-rewards` — расчёт монет, `#daily-rewards` — ежедневные награды. Например, к реальному URL справки можно добавить `#currency`, чтобы открыть сразу этот раздел. Все разделы перечислены в оглавлении.

Страница справки полностью статическая и содержит весь текст в HTML: её можно открыть напрямую, без авторизации, захода на главную или JavaScript. Язык можно переключить кнопками RU/EN. Подробный текст взят из раздела для сайта файла `Noir_2048_Help_Rework.md`; служебные указания и промпт не опубликованы. Числовые значения сохранены, включая 1 кристалл за суммарный счёт 1 000 000 000.

## Демо

Поле 4×4, две стартовые двойки, после успешного хода 2 (90%) или 4 (10%). Одна плитка сливается один раз за ход. Очки равны номиналу результата. При 2048 партия продолжается.

Одно бесплатное удаление на партию, без очков и спавна. Последнюю плитку удалить нельзя. При тупике предлагается оставшееся удаление или завершение. Кнопка RuStore доступна постоянно и выделена после завершения.

Свайпы, перетаскивание мышью, стрелки и WASD. Стрелки действуют, когда фокус находится на поле; кликните поле или ссылку «Попробовать здесь».

Три оригинальных набора SVG из Tiles.zip: Classic, Monochrome (золотое оформление), Северное сияние. Все доступны бесплатно в демо; это не обещание бесплатной доступности стилей в Android-приложении.

Демо не содержит рекорда, магазина, рекламы, игровой валюты или музыки. Звуковые файлы не предоставлены. Партия живёт в памяти страницы: перезагрузка её сбрасывает, переключение языка или оформления — сохраняет. Cookie, localStorage, аналитика и внешние шрифтовые сервисы не используются.
